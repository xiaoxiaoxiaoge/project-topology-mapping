# 阶段 6: 完整性校验

**生成拓扑文件并存储到记忆后，逐项检查是否完整。任何一项为"否"必须补充后再继续。**

> 前置：阶段 5 已完成。
> 后置：进入 [阶段 7: 同类模块差异识别](./phases/phase7_differences.md)

## 6.1 通用校验清单（所有项目类型）

- [ ] **6.1.7** 是否有数据流章节？

  - [ ] Store/缓存 状态数据流图
  - [ ] 路由守卫/安全过滤链 数据流图
  - [ ] 至少一个核心页面/Controller 的完整数据流
  - [ ] 模块间关系图
- [ ] **6.1.8** 是否列出所有入口命令和端口？

## 6.3 项目类型特定校验

### 前端项目

- [ ] **6.3.F5** 路由守卫逻辑是否画出完整数据流（含 token 刷新、权限码校验）？

### 后端项目（Java/Go/Python/Node/.NET/Rust）

- [ ] **6.3.B7** 缓存策略（`@Cacheable` / Redis）是否说明？

### 移动端（Android/iOS/RN/Flutter）

## 6.4 校验失败处理

如果任何一项为"否"：

1. **不要继续**进入阶段 7
2. 回到对应阶段补充缺失内容
3. 重新跑校验
4. 校验全绿后再进入阶段 7
