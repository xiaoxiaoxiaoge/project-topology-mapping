# 阶段 4: 生成拓扑文件

**根据用户在阶段 1 确认的项目类型和阶段 0 的扫描深度选择模板。**

> 前置：阶段 1-3 已完成。
> 后置：进入 [阶段 5: 存储到记忆](./phase5_memory.md)

---

## 4.0 文件分离决策

### 单端项目（纯前端 / 纯后端 / 纯移动端 / 纯小程序 / 纯桌面端 / 纯 HarmonyOS）

只生成**单一文件** `.project-topology.md`。

### 多端项目（前端+后端 / 全栈 / 含移动端+服务端）

默认生成**分离式拓扑文件**：

| 文件 | 内容 | 适用场景 |
|------|------|---------|
| `.project-topology.md` | 主索引文件，汇总信息 + 跳转链接 | 快速了解全项目 |
| `.project-topology-frontend.md` | 前端完整拓扑 | 修改前端页面/组件/状态 |
| `.project-topology-backend.md` | 后端完整拓扑 | 修改后端 Controller/Service/微服务 |
| `.project-topology-mobile.md` *(可选)* | 移动端完整拓扑 | 修改 App 页面/原生模块 |

> 用户可以在阶段 1 之前主动说"合并"或"分离"覆盖默认值。

```markdown
| 文件 | 内容 |

| [.project-topology-backend.md](./.project-topology-backend.md) | 后端完整拓扑 |

## 快速定位

| 定位需求 | 跳转文件 |

## 技术栈概览
（关键技术、版本、核心依赖）

## 微服务概览
（全栈项目必填）

## 数据流概览
（HTTP/状态/守卫的关键链路摘要）

## 入口点
（开发命令、端口、关键 URL）
```

## 4.2 前端/移动端/小程序拓扑文件结构

```markdown
# [类型]项目拓扑 - [项目名称]

**关联文件:** [.project-topology.md](./.project-topology.md)

## 1. 基础信息
## 2. 目录结构（树状图）
## 3. 模块地图（模块名/路由前缀/子模块数/主要页面）
## 4. 组件关系图
   - 组件层级树
   - 页面模块统一结构模式
   - 共享组件引用表（Top 20 按引用次数排序）
   - 组件依赖关系示例
## 5. 数据流图
   - HTTP 请求数据流
   - Store/缓存 状态数据流
   - 路由守卫数据流
   - 核心页面数据流（至少一个完整示例）
   - 模块间关系图
## 6. 入口点（命令、端口）
## 7. 路由模块表
## 8. 依赖列表
## 9. 定位速查表（精简版/详细版）
```

## 4.3 后端拓扑文件结构

```markdown
# 后端项目拓扑 - [项目名称]

**关联文件:** [.project-topology.md](./.project-topology.md)

## 1. 基础信息
## 2. 目录结构（树状图）
## 3. 微服务概览
## 4. 服务详情（每个微服务一节）
## 5. 服务端完整路由清单（按 Controller 分组）
## 6. 业务实现（Feign 调用链 / 事务边界 / 异常处理）
## 7. 数据流图
   - HTTP 请求数据流
   - 缓存状态数据流
   - 安全过滤链数据流
   - 核心 Controller 数据流
## 8. 微服务定位速查
## 9. 入口点（命令、端口）
## 10. 依赖列表
## 11. 服务名交叉验证（详见 types/backend.md 末尾）
```

## ✅ 必含章节检查清单

生成后**逐项确认**（任何一项缺失，阶段 6 校验会失败）：

### 通用必含

- [ ] **4.A** 基础信息（生成时间、项目名称、语言、框架、项目类型）
- [ ] **4.B** 完整目录结构树
- [ ] **4.C** 模块地图表
- [ ] **4.D** 组件关系图（含共享组件引用表 Top 20）
- [ ] **4.E** 数据流图（HTTP/Store/守卫/核心页面 4 个子图）
- [ ] **4.F** 入口点（命令、端口）
- [ ] **4.G** 路由模块表
- [ ] **4.H** 依赖列表

### 全栈项目额外必含

- [ ] **4.I** 前后端定位速查表（详细版/精简版）
- [ ] **4.J** 微服务定位速查
- [ ] **4.K** 服务名交叉验证（含 @FeignClient name / Go Eureka 注册名）

### 单类型项目类型特定

- 前端: 共享组件引用表 + 路由模块表
- 后端 Java: Controller 路由表 + Service 方法签名 + Feign Client 列表
- 后端 Go: Handler 路由表 + Middleware 链
- 移动端: 页面生命周期差异 + 原生模块调用表
- 小程序: 页面路径表 + 组件引用表
- 桌面端: Main/Renderer 进程边界 + IPC 通道表
- HarmonyOS: ArkTS 页面依赖链 + Native 绑定架构

各项目类型的具体输出模板见 `../templates/` 目录。
