# Pull Request 模板

感谢你为本项目提 PR！🎉

请填写以下信息，CI 会自动跑校验。

## 改动类型

请勾选：

- [ ] 🐛 Bug 修复
- [ ] ✨ 新功能
- [ ] 📖 文档改进
- [ ] ♻️ 重构（无功能变更）
- [ ] ⚡ 性能优化
- [ ] 🧪 测试
- [ ] 🔧 杂项（CI / 依赖等）

## 关联 Issue

- 关联 issue: #xxx
- 关闭 issue: fixes #xxx

## 改动描述

简要描述本次改动。

## 改动清单

- [ ] 改动 1
- [ ] 改动 2

## 自测清单（精简）

- [ ] 我在自己的环境跑通了
- [ ] 我没引入跨平台不兼容命令（`head` / `tail` / `wc -l` 在 PowerShell 不存在）
- [ ] 我没破坏 single source of truth 原则

> 📖 完整 checklist（含"更新文档/CHANGELOG/加测试"等）见 [CONTRIBUTING.md § 开发流程](../CONTRIBUTING.md#开发流程)

## 截图 / 录屏

如有视觉 / 交互改动，请附上截图或录屏。

## 额外说明

其他需要 reviewer 注意的信息。
